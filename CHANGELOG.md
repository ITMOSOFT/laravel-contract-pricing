# Changelog

All notable changes to `itmosoft/laravel-contract-pricing` are documented here.

## [1.0.0] - 2026-11-17

- Add polymorphic customer-specific price lists.
- Add product-specific contract prices with currency and quantity breaks.
- Add effective date windows and active/inactive controls.
- Add price resolution service with quantity-tier selection.
- Add configurable model and table names.
